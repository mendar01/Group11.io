## Tier 2 — Academic language for presenting (functional vocabulary)

Use these to signal structure, cause and effect, and to hedge, which is what academic presentations are graded on.

### Signposting
- *Today we are going to focus on …*
- *First of all, I will define …; then [Name] will examine …*
- *I'd like to begin by outlining three causes.*
- *That brings me to my second point.*
- *Now let's move on to the question of solutions.*

### Cause and effect
- *This can be attributed to …*
- *One of the main drivers of this trend is …*
- *The main consequence of this is …*
- *As a result, … / Consequently, … / This, in turn, leads to …*

### Referring to data
- *According to the World Inequality Report …*
- *The latest OECD figures suggest that …*
- *Data from the Federal Reserve indicate a similar pattern.*
- *This figure has risen / fallen sharply since 1990.*
- *Roughly / approximately / just under a half of …*

### Hedging (essential in EAP)
- *The data suggests that …* (not *proves*)
- *This is likely to be the result of …*
- *It would appear that …*
- *One possible explanation is …*
- *This tends to be the case in OECD countries.*

### Referring to the counter-argument
- *It could be argued that …*
- *Critics of this view point out that …*
- *While this may be true in some cases, …*
- *This argument has some merit, but …*

### Handing over to the next speaker
- *I'll now hand over to [Name], who will talk about the evidence.*
- *That leads me to pass on to [Name].*
- *To explore that question further, here is [Name].*

## Tier 3 — Pronunciation focus

| Word | Common mistake | Correct |
|------|----------------|---------|
| inequality | /ɪnˈekwələti/ | **/ˌɪnɪˈkwɒləti/** — the stress is on "kwol" |
| Gini | "gee-nee" (as in *gene*) | **/ˈdʒiːni/** — as in *jeans*, the *G* is soft |
| wealth | /welθ/ (with *th* voiced wrongly) | **/welθ/** — voiceless *th*, one syllable only |
| eighth / percentage | dropped sounds | *percentage* has three syllables: per-CEN-tage |
| **the** top 1% | /ðə/ before a vowel sound | **/ðiː/** *top* — practice: "thee top one per cent" |
| economy / economic / economical | wrong stress | e-CON-omy · e-co-NOM-ic · e-co-NOM-i-cal |
| inequality vs. inequity | confusable | inequality = measurable gap · inequity = unfairness |

## Pronunciation drill (2 minutes, do this before you present)

Read aloud, stressing the **bold** syllable:

> The **Gi**ni co**eff**icient · wealth con-cen**TRA**-tion · in-e**QUAL**-i-ty · so-cial mo**BIL**-i-ty · wage stag**NA**-tion · in**HER**-i-tance · pro**GRESS**-ive tax-**A**-tion · re-dis-tri**BU**-tion · ex**A**-cer-bate · **MIT**-i-gate

Full sentence drill:

> "The **top** ten per cent of the world's population takes **fifty-two** per cent of global income, while the **bottom** half shares only **eight point five** per cent."
